# 経費科目の判定ルール

経費科目を判定するときは、購入内容と利用目的を確認し、
以下の基準に合致する科目を選択してください。

複数の科目が候補になる場合や、判断に必要な情報が不足している場合は、
推測で確定せず、ユーザーへ確認してください。

## 新聞図書費

業務上必要な書籍、技術書、専門誌、電子書籍など。

### 例

- Javaの技術書
- Spring Bootの技術書
- AWSの技術書
- 業務に必要な資格試験の参考書

## 消耗品費

業務で使用する少額の物品。

### 例

- 文房具
- マウス
- キーボード
- USBケーブル

## 旅費交通費

業務上必要となった移動費。

### 例

- 電車
- バス
- タクシー

## 会議費

業務上の会議や打ち合わせに伴う支出。

### 例

- 社外との打ち合わせ時の飲食
- 会議用の飲料

## 通信費

業務上必要な通信に関する支出。

### 例

- インターネット利用料
- 携帯電話料金
- 郵送料

## 判断できない場合

ルールだけでは経費科目を特定できない場合は、
推測で確定せず、ユーザーへ利用目的などを確認してください。
